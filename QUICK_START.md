# Pro Caption AE - Quick Start Guide

Welcome to Pro Caption AE! Get started with AI-powered captions in After Effects in 5 minutes.

## ⚡ Quick Setup (5 minutes)

### 1. Install the Extension
- Download the latest `.zxp` from [Releases](https://github.com/64r3al/Pro-Caption-AE/releases)
- Drag it into your After Effects window
- Restart After Effects

### 2. Get Your API Key
- Sign up at [Groq Console](https://console.groq.com/)
- Create an API key (free tier available)
- Copy it to clipboard

### 3. Configure Settings
1. Open **Window → Extensions → Pro Caption AE**
2. Click the **⚙️ Settings** icon
3. Paste your Groq API key
4. Click **Save**

### 4. Create Your First Captions
1. Open a composition with audio
2. Click **"Select Audio"** in Pro Caption AE
3. Click **"Transcribe"**
4. Choose your animation style
5. Click **"Build Captions"**

Done! 🎉 Your animated captions are ready.

## 🔑 API Key Setup

### Getting a Free Groq API Key
1. Go to [Groq Console](https://console.groq.com/)
2. Click **"Sign Up"** (email/password or Google/GitHub)
3. Verify your email
4. Go to **API Keys** section
5. Click **"Create New API Key"**
6. Copy the key and paste into Pro Caption AE Settings

### Free Tier Details
- **Requests/Month**: Generous free quota
- **Models**: Access to Whisper, Llama, Mixtral
- **Support**: Community support available
- **Upgrade**: Scale as you grow

## ❓ Troubleshooting

### "Extension not appearing"
- ✓ Make sure you're on After Effects 2024+
- ✓ Restart After Effects after installation
- ✓ Check Window → Extensions menu

### "API key error"
- ✓ Verify your key is correct (copy from Groq console)
- ✓ Make sure you have internet connection
- ✓ Check that your API quota hasn't been exceeded

### "No audio detected"
- ✓ Ensure audio layer is in your composition
- ✓ Make sure audio track is not muted
- ✓ Check that you've selected the right layer

### "Timing seems off"
- ✓ Verify your audio sample rate (typically 48kHz for video)
- ✓ Try using the "Refine Timing" option
- ✓ Check for audio gaps or silence at start

## 🎓 Tips & Tricks

### Get Better Captions
- Use clean, clear audio (minimal background noise)
- Avoid simultaneous overlapping speakers
- Use glossary for industry-specific terms
- Break long videos into segments

### Speed Things Up
- Use shorter video segments
- Pre-process audio for clarity
- Cache transcriptions when possible
- Batch similar videos together

### Creative Techniques
- Mix multiple preset styles
- Adjust keyframe timing manually
- Combine with other plugins
- Layer animations for emphasis
